# Whisk Bakery

## Stack
- MongoDB 
- Express.js
- React Vite
- Node.js

## Features:

- Users can sign up and login
- Users can add and remove products to a cart
- Users can view and search products

- An administrator is able to add products, set prices, manage inventory, etc.
